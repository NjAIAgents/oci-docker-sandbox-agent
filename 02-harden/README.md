## What this does

A freshly provisioned Ubuntu VM on a public IP is exposed the moment it boots.
Before installing anything else, this playbook applies a baseline security posture:

1. **OS updates** — full package upgrade + unattended security upgrades enabled
2. **`ods` user** — non-root sudo user with SSH key access; all future posts use this user
3. **SSH hardening** — root login disabled, password auth disabled, key-only access
4. **`ufw` firewall** — port 22 allowed, all other inbound traffic denied
5. **`fail2ban`** — SSH jail: 5 failed attempts → 1-hour IP ban
6. **4 GB swap** — prevents OOM on agent workloads (A1.Flex has no swap by default)

---

## Prerequisites

- Post 1 complete — VM is running, you can SSH in with `ssh ubuntu@<VM_PUBLIC_IP>`
- `.env` file exists at repo root with `VM_PUBLIC_IP` and `VM_SSH_KEY` set
- Ansible installed locally:
  - macOS: `brew install ansible`
  - Linux: `pip3 install ansible`

---

## Quick start

```bash
git pull
make harden
```

After it completes, connect as the new user:

```bash
ssh ods@<VM_PUBLIC_IP>
```

---

## What changes in .env

Uncomment these lines in your `.env` after Post 2 completes:

```bash
VM_USER=ods
ODS_SSH_KEY=~/.ssh/id_ed25519   # path to the private key for the ods user
```

All subsequent `make ssh` calls will use `ods` instead of `ubuntu`.

```
├── ansible.cfg     # Local Ansible config
└── inventory.ini   # Generated by setup.sh — gitignored, never committed
```

---

## Manual verification

After `make harden` completes:

```bash
# SSH as ods user
ssh ods@<VM_PUBLIC_IP>

# Check firewall
sudo ufw status

# Check fail2ban
sudo fail2ban-client status sshd

# Check swap
free -h

# Confirm root SSH is blocked
ssh root@<VM_PUBLIC_IP>   # should get: Permission denied
```
